# AeroOps IROPS Platform

A  project focused on airline irregular operations (IROPS), built to demonstrate backend engineering, TypeScript, Node.js, and AWS architecture skills.

## Goal
Simulate an airline operations platform that can register and process operational incidents such as delays, cancellations, and gate changes.

## Tech Stack
- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + TypeScript
- AWS target: Lambda, API Gateway, DynamoDB, SQS

## Version 1 Scope
- Landing page
- Incident creation form
- Incident list dashboard
- Local backend API
- Later migration to AWS services
